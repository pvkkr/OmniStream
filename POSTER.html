The Motivation

Why I Built OmniStream

"I was completely tired of using sketchy, ad-riddled websites, scam 'Download' buttons, and random Telegram bot channels that spam you with promos, throttle your speed, or suddenly stop working just to download a 30-second clip from Instagram, Twitter, or YouTube."

✕ No more sketchy Telegram bots going offline
✕ No more fake malware & popup ads
✕ No forced low-quality 360p compression

Core Capabilities & Architecture

🌐

Universal Platform Engine

One single link bar handles 1,000+ sources: YouTube, Instagram Reels, X/Twitter, TikTok (no watermark), Reddit, Vimeo, Facebook, Twitch, and direct m3u8 HLS streams.

YouTube Instagram X / Twitter TikTok Reddit
🎬

Quality & Size Inspector

Choose your exact resolution: 4K Ultra HD (2160p 60fps), 2K, 1080p, 720p, 480p, plus 320 kbps MP3 & M4A audio. Shows exact estimated file sizes before downloading.

4K 60fps 1080p FHD 320k MP3 Size Preview
🍿

True VLC Timeline Seeking

Eliminates the dreaded VLC "reset to 0:00" bug. Features ⚡ Buffer & Seek and HTTP continuous auto-reconnection so you can scrub, rewind, and skip forward without dropouts.

Shift+Arrows (3s) Alt+Arrows (10s) Zero Resets
🛡️

Anti-Bot & SABR Bypass

Intelligent client fallback: when YouTube blocks desktop scrapers with "This video is not available", OmniStream automatically pivots to mobile client APIs to extract the media seamlessly.

Auto Fallback Mix Sanitizer 1-2s Response
⚡

Bundled FFmpeg Merging

Includes bundled high-performance FFmpeg binary. Automatically merges standalone high-bitrate video streams with original audio into a single clean MP4/MKV file at up to 25+ MB/s.

MP4 / MKV Live Speed MB/s ETA Countdown
📱

Desktop & Mobile Freedom

Run the modern dark PyQt5 desktop app on Windows, or install the companion Android APK with built-in Wi-Fi transfer server and swipe-to-seek VLC for Android support.

Windows PyQt5 Android APK Wi-Fi Share
Tech Stack: Python 3.14 PyQt5 (Dark Theme) yt-dlp Engine FFmpeg v7.1 VLC Media Player
